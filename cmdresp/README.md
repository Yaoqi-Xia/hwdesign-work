Set the grader timeout to at least 100 seconds for Part 4. The course
requires a **public** repository because the grader cannot authenticate.
The agent has not submitted to the grader, obtained grader feedback or
performed an in-class peer prompt exchange. Do not describe those steps
as completed. Review the prompt and results, then submit them in the
course grader; preserve and address any feedback it returns.

The take-home design is an 8-tap configurable fixed-point FIR. The
in-class design is float32 scale and offset. The implementation includes
the model, HLS kernel, testbench, replayable vectors and raw evidence.
Read each `results.md` for verification and the recorded performance miss.

The repository was created during this session because no course-work
repository existed. The prompt was pushed before the final implementation
upload. Earlier local runs predate that repository; no earlier commit,
pre-run push, grader response or human-authored review is fabricated.
