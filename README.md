# Hardware Design Coursework

Unit 5 command-response accelerator specifications and verified implementations.

- `cmdresp/inclass/`: float32 scale and offset, through C simulation.
- `cmdresp/takehome/`: configurable Q1.15 FIR, through synthesis and RTL co-simulation.

The specification commit precedes the final implementation upload. Earlier local development occurred before this repository existed; no earlier push is claimed.
